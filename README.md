# Banoy

Banoy is an AI-powered personal finance product designed to help users understand their financial situation, choose a strategy, and turn it into concrete actions.

## What Banoy does

- Collects income, expenses, and liabilities
- Builds a structured financial overview
- Helps users compare financial strategies
- Creates a personalized 7-day action plan
- Supports ongoing financial decision-making
- Integrates with Telegram for reminders and user actions

## Tech stack

- Next.js
- TypeScript
- Supabase
- PostgreSQL
- AI / LLM integration
- Telegram integration
